# Review Requests

Use these after installing and selecting the Review skill. Upload only material you are authorized to process. Examples do not grant permission to send confidential content to additional services.

## General Manuscript Review

```text
$review Review the attached manuscript and supplementary files. Verify relevant literature, prioritize the issues that most affect the paper's argument, and return the six-section report in English.
```

## 投稿前審查

```text
$review 請審查這份論文與補充資料，優先檢查創新性、方法、結果與結論是否一致。所有補充引用必須實際查證並附 DOI 或原始網址，以繁體中文輸出六段正式審查意見。
```

## Multi-Omics and Single-Cell Research

```text
$review Review the supplied multi-omics manuscript. Pay particular attention to donor-level inference, batch effects, cross-modal sample alignment, preprocessing leakage, validation, and the limits of biological claims. Recommend analyses using existing data where feasible, rather than proposing a new study by default.
```

## Qualitative and Mixed-Methods Research

```text
$review 審查這份 mixed-methods 論文。先辨識質性分析取向，再檢查訪談引述、問卷結果、triangulation、joint display 與整合推論。不要對反身性主題分析制式要求編碼者一致性，也不要用正向訪談抵銷量化未顯著的結果。
```

## Abstract-Only Review

```text
$review I can provide only the abstract. Give a bounded review, clearly identify what cannot be assessed, and do not infer missing controls or methods from the absent full text.
```

## ChatGPT

When the current ChatGPT client has actually installed the skill, select Review from its `@` menu and use the same request text. The `$review` examples above are Codex syntax; they do not automatically select a skill in other products.
